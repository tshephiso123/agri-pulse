# UI components

Local JavaScript adaptations of the MIT-licensed shadcn/ui component composition, with 48 px or larger controls and a Tailwind 3 theme.

References: https://ui.shadcn.com/docs/components/button, https://ui.shadcn.com/docs/components/input, https://ui.shadcn.com/docs/components/card, https://ui.shadcn.com/docs/components/alert, https://ui.shadcn.com/docs/components/empty, https://ui.shadcn.com/docs/components/skeleton, https://ui.shadcn.com/docs/components/dialog.

Dialog uses Radix for focus trapping and Escape handling. Empty-state SVG icons come from the ISC-licensed Lucide package and are bundled locally for offline use.
